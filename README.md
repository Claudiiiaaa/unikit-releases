# UniKit 🎓

Kit de utilidades de escritorio para la uni.

**[⬇️ Descargar la última versión](https://github.com/Claudiiiaaa/unikit-releases/releases/latest)**: baja el archivo `UniKit-Setup-….exe` y ábrelo.

## Qué incluye

- **PDF → Markdown**: convierte apuntes y PAC en texto limpio (también PDF escaneados, con OCR).
- **Imagen → texto**, **Fotos → PDF**, **Unir PDF**, **Extraer páginas**, **Buscar en apuntes**.
- **Contador de palabras**, **citas APA** desde un DOI o un ISBN, **fórmulas LaTeX**.
- **Entregas**, **notas** («¿qué necesito para aprobar?») y **Pomodoro**.
- **Física** (unidades, fotones, constantes) y **bases numéricas** con los pasos.

## Instalación

1. Descarga `UniKit-Setup-x.y.z.exe` desde [la última versión](https://github.com/Claudiiiaaa/unikit-releases/releases/latest).
2. Ábrelo. Si Windows muestra **«Windows protegió su PC»**, pulsa **Más información → Ejecutar de todas formas**
   (sale porque el programa no está firmado digitalmente, no porque tenga nada malo).
3. Listo: se crea un acceso directo en el escritorio. No hace falta ser administrador.

**Requisitos:** Windows 10 (versión 2004 o posterior) u 11, de 64 bits.

## Actualizaciones

UniKit avisa sola cuando hay una versión nueva. Pulsa **Actualizar** y se instala en un momento,
sin perder tus asignaturas, notas ni entregas.

## Privacidad

Todo funciona en tu ordenador: no hay cuentas ni se envían tus datos a ningún sitio.
Solo se conecta a internet para buscar citas (Crossref, Open Library, Google Books) y para
comprobar si hay una versión nueva. Tus datos se guardan en `%APPDATA%\UniKit`.
